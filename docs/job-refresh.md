# Daily Subscrape refreshes

The signed Mac app revisits tracked external job sources at most once per 24 hours after each successful refresh/upload. It checks on launch, after hourly scrapes complete, and hourly while it remains open. The existing 09:00 Puerto Rico Codex review launches the app with `--refresh-jobs` and waits for the status before syncing uploads. Keep the Mac awake with Codex running; Subscrape may also stay open or be launched by the existing hourly workflow. This is an app timer, not a Cloudflare Reddit crawler; Arc cookies stay on the Mac.

`GET /api/job-board/refresh-targets` exposes source identities, original URLs, and titles only for previously published external jobs still published or awaiting rereview. It includes stale jobs hidden from the public search feed so they can recover. Never-published candidates, private source bodies, submitters, rejected/closed jobs, and passed closing dates are excluded. Responses cache for 60 seconds and are capped at 500 sources with an explicit `truncated` flag. Subscrape records a partial result if the cap is reached.

The Mac fetches each exact source through its existing Arc Reddit session. Available text, edited text, and explicit deletion/removal markers become complete source records. Blocked, failed, malformed, missing-comment, or missing-original-date responses do not advance freshness and are not treated as deletion evidence. Successful records carry the real `capturedAt` and a UTC `refreshDay`. Only this dedicated fresh-fetch path sets the observation marker.

The authenticated Subscrape storage Worker retains one daily observation per source/revision/day even when the text is unchanged. Other contact/source deduplication stays the same. Uploads save an immutable pending payload and filename before delivery; a timeout or restart retries that same batch. State/checkpoints advance only after an acknowledged upload. The existing R2 importer consumes these `type: source` records and updates the same canonical source. Repeated observations do not create extra jobs, reset the validation window, or add qualifying-supply credit.

Fresh captures do not auto-approve or renew listings. The daily review agent reads the newest source capture and applies the existing terms, closure, deadline, and duplicate checks before renewing. Edits still withdraw a job for rereview; explicit removed/deleted sources close it. If fetching stops, the existing seven-day expiry remains in effect.

Source implementation: `/Users/codybontecou/dev/subscrape/desktop/job-refresh.cjs`, its `desktop/main.cjs` scheduler, `cloud/dedup.js`, and `docs/daily-job-refresh.md`. The app writes `job-refresh-status.json` in its userData folder (on this Mac, `~/Library/Application Support/Subscrape/`) with counts, stage, pending-upload and failure flags. The adjacent private `job-refresh-state.json` stores due times and an immutable pending source record; do not expose it publicly. The status summary contains no source bodies, contact data, cookies, or credentials.
