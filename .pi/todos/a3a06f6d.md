## Overview
Extract the current bake-time injections from `portfolio-generator.ts` into a serve-time injection module. This is the key architectural change — platform concerns (tracking, contact forms, analytics) get injected when serving, not when generating. This means platform-wide updates apply to ALL portfolios instantly with a single deploy.

## Tasks
- Create `lib/portfolio/platform-injections.ts` with:
  - `injectPlatformCode(html: string, subdomain: string): string` — injects into HTML:
    - Tracking pixel (currently in `injectTrackingAndContactForm`)
    - Favicon links
    - Any future head/body injections (analytics, cookie banner, badges, etc.)
  - `getContactFormHandler(subdomain: string): string` — returns the contact form JS handler (currently baked into script.js in `injectTrackingAndContactForm`)
  - `getPlatformHeadTags(subdomain: string): string` — meta tags, analytics scripts
  - `getPlatformBodyTags(subdomain: string): string` — tracking pixel, footer badge

## Key design decisions
- HTML injection uses `</head>` and `</body>` replacement (same pattern as current `injectTrackingAndContactForm`)
- Contact form handler appended to script.js at serve-time
- All injection functions are pure (no DB calls) — the serving route handles auth/access checks separately
