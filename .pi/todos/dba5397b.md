## Overview
Create a migration script that downloads portfolio files from existing GitHub repos and re-uploads them to Vercel Blob. This migrates live creator sites without downtime.

## Tasks
- Create `scripts/migrate-portfolios-to-blob.ts`:
  1. Query all users with `githubRepoFullName IS NOT NULL`
  2. For each creator:
     a. Initialize Octokit with service token
     b. Fetch the repo's file tree (Git Data API or contents API)
     c. Download each file (index.html, styles.css, script.js, favicons, etc.)
     d. **Strip baked-in platform code** from downloaded files:
        - Remove the tracking pixel from index.html
        - Remove the contact form handler from script.js
        - Remove the injected favicon HTML snippet (or keep it — favicon links are harmless)
        - This is important so serve-time injection doesn't double-inject
     e. Upload raw files to Blob via `uploadPortfolio(subdomain, files)`
     f. Log success/failure per creator
  3. Summary report at end

## Stripping baked-in platform code
The current `injectTrackingAndContactForm` adds:
- In `index.html`: `<!-- Portfolio Analytics -->` + tracking pixel before `</body>`
- In `script.js`: The entire `// Contact Form Handler (UGC Community Integration)` IIFE at the end

For the migration script, strip these by:
- Removing everything between `<!-- Portfolio Analytics -->` and the tracking `<img>` tag
- Removing everything from `// Contact Form Handler (UGC Community Integration)` to end of file in script.js

## Rollback safety
- Don't delete GitHub repos yet (that's Phase 9)
- Don't change `siteEnabled` or Vercel project config during migration
- This is an additive step — portfolios exist in both places temporarily

## Running the migration
- Run locally: `npx tsx scripts/migrate-portfolios-to-blob.ts`
- Needs env vars: `GITHUB_SERVICE_TOKEN` (or `GITHUB_ACCESS_TOKEN`), `BLOB_READ_WRITE_TOKEN`
