## Overview
Build the foundational infrastructure for a tutorials/guides system inside the dashboard.

## Tasks

### MDX Setup
- Install MDX dependencies (`@next/mdx`, `next-mdx-remote`, or similar)
- Create `content/tutorials/` directory for `.mdx` files
- Build MDX renderer with custom components (code blocks, callouts, checklists, copy-to-clipboard)
- Style prose content to match the warm-gray/coral design system

### Routing
- Create `app/(dashboard)/dashboard/tutorials/page.tsx` — tutorial index/hub with card grid
- Create `app/(dashboard)/dashboard/tutorials/[slug]/page.tsx` — individual guide renderer
- Add frontmatter support (title, description, icon, order, category, estimatedReadTime)

### Navigation Integration
- Add "Tutorials" to `components/dashboard/nav.tsx` navItems array with `BookOpen` icon
- Route: `/dashboard/tutorials`
- Ensure mobile nav also includes the new item

### Tutorial Index Page
- Card-based grid layout showing all available guides
- Each card: title, description, icon, estimated read time, category badge
- Group by category (Getting Started, Content Creation, Growth & Strategy)
- Progress tracking consideration (future: mark guides as "read")

### Design
- Match existing dashboard aesthetic (warm-gray-50 bg, rounded-xl cards, coral accents)
- Responsive layout
- Table of contents sidebar for individual guides (desktop)
- Smooth reading experience with proper typography
