## Overview
Add a preview step where creators (or admins) can see the generated site and provide natural language feedback for iterative refinement before publishing.

## Tasks
- **Preview infrastructure:**
  - After generation, upload to a preview path in Blob (`portfolios/{subdomain}/_preview/`)
  - Serve previews at a different URL pattern (e.g., `preview-{subdomain}.ugc.community` or `ugc.community/preview/{subdomain}`)
  - Don't activate `siteEnabled` until the creator approves
- **Feedback API:**
  - Create `POST /api/user/portfolio-preview/feedback` endpoint
  - Accepts `{ generationId, feedback: string }` (natural language)
  - Triggers a new Inngest event: `portfolio/iterate.requested`
- **Iteration generation:**
  - Create a new Inngest function `iterate-portfolio` that:
    - Loads the existing generated files
    - Sends them back to Claude with the original prompt + `## Creator Feedback` section
    - Claude modifies the files based on feedback (uses read_file + write_file tools)
    - Uploads the updated preview
  - Limit iterations (max 3 per generation to control costs)
- **Approval flow:**
  - `POST /api/user/portfolio-preview/approve` — moves preview files to live path, enables site
  - `POST /api/user/portfolio-preview/reject` — discards preview, allows starting over
- **Admin panel:**
  - Add preview URL to the admin questionnaire/generation view
  - Add "send feedback" / "approve" / "reject" buttons
- **DB changes:**
  - Add `iterationCount` to `portfolioGenerations`
  - Add `previewStatus: 'pending_review' | 'approved' | 'rejected'` to `portfolioGenerations`
  - Store feedback history (could be a separate `portfolioFeedback` table or JSON array)

## Files

- `lib/db/schema.ts` (modify)

## Acceptance Criteria
- Generated portfolios land in preview before going live
- Creators can provide text feedback ("make it darker", "bigger images")
- Feedback triggers a targeted iteration (not full regeneration)
- Max 3 iterations per generation
- Approval publishes to live; rejection allows restart
- Admin can manage the preview/approval flow
