## Overview
Create `lib/portfolio/storage.ts` — the core storage module for uploading, listing, and deleting portfolio files in Vercel Blob.

## Tasks
- Create `lib/portfolio/storage.ts` with:
  - `uploadPortfolio(subdomain, files: GeneratedFile[])` — uploads all files to `portfolios/{subdomain}/{filename}`
  - `deletePortfolio(subdomain)` — deletes all blobs under a subdomain prefix
  - `getPortfolioFileUrl(subdomain, filePath)` — returns the blob URL for a specific file
  - `portfolioExists(subdomain)` — checks if a portfolio has files in blob
  - Content-type mapping for `.html`, `.css`, `.js`, `.json`, `.png`, `.ico`, `.webmanifest`
- Use `@vercel/blob` (`put`, `del`, `list`) — already in dependencies and used by `lib/storage/blob-client.ts`
- Use `addRandomSuffix: false` so paths are deterministic and overwritable
- Handle both text files and binary files (favicons — `isBinary: true` uses base64 in `GeneratedFile`)
