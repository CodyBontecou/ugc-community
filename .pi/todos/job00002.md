Brand submissions are free and manually reviewed. Applications currently go to the original employer destination.

- Define privacy-conscious employer feedback or application attribution that can measure qualified applications, not just outbound clicks.
- Validate repeat hiring demand before offering paid featured placement or recurring hiring tools.
- Consider review history, source-level import health, report-an-expired-job UI, and notification preferences once usage establishes which tools matter.
- For larger import volumes, add queued per-object ingestion and archival reconciliation instead of increasing the bounded cron workload indefinitely.
