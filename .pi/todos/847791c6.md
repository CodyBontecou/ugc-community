## Overview
Create a design seed system that randomly selects a curated aesthetic direction before each portfolio generation, ensuring no two sites look alike.

## Tasks
- Create `lib/agent/design-seeds.ts` with a registry of 30+ curated seed combos
- Each seed should define:
  - Color palette (primary, secondary, accent, background, text) with hex values
  - Typography pairing (display font + body font) with Google Fonts import URLs
  - Layout archetype (e.g., "editorial magazine", "horizontal scroll", "bento grid", "asymmetric overlap")
  - Mood keywords (e.g., "brutalist, raw, industrial")
  - Theme (light/dark/mixed)
- Add a `selectDesignSeed()` function that picks a random seed
- Add a `## Design Direction` section to the user prompt in `portfolio-prompt.ts` with the selected seed
- Track which seed was used in the `portfolioGenerations` table (add a `designSeedId` column)

## Curated Seeds to Create (examples)
1. Warm editorial — Playfair Display + Source Serif, terracotta/cream/charcoal, magazine layout
2. Neon brutalist — Space Mono + IBM Plex Sans, black/neon green/white, raw grid
3. Soft luxury — Cormorant Garamond + Nunito Sans, champagne/slate/ivory, centered minimal
4. Retro pop — Archivo Black + DM Sans, coral/mustard/navy, bold overlapping blocks
5. Nature organic — Lora + Karla, forest green/sand/cream, flowing sections
6. Tech dark — JetBrains Mono + Inter, deep navy/cyan/charcoal, dashboard-style grid
7. Art deco — Poiret One + Raleway, gold/black/cream, geometric borders
8. Pastel dreamy — Quicksand + Poppins, lavender/peach/mint, rounded cards
9. Swiss modern — Helvetica Neue + Libre Baskerville, red/white/black, strict grid
10. Cyberpunk — Orbitron + Exo 2, purple/hot pink/black, glitch effects
... (build out to 30+)

## Acceptance Criteria
- Every generation gets a randomly selected design seed
- Seed details are injected into the prompt as concrete directives (not suggestions)
- Seed ID is persisted so we can track/avoid repeats
- At least 30 curated seeds covering diverse aesthetics
