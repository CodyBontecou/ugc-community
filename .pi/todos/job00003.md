Daily app refreshes fetch previously published source URLs, upload unchanged daily observations, and feed the existing importer and review agent. Check Subscrape's job-refresh-status.json for persistent failures, pending uploads or a truncated target list. Check source_captured_at after imports. A missing/private/blocked response must not refresh a job; keep evidence expiry if failures persist. If tracked volume approaches 500, add pagination/queues before increasing caps. Mac sleep/app closure still prevents local refreshes; assess a hosted authenticated collection service only if unattended Mac availability becomes insufficient.
