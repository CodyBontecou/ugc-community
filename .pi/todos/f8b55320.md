## Overview
After cutover is stable (give it a few days), remove all the now-unused GitHub/Vercel infrastructure code, admin API routes, and deprecated DB fields. This is the "delete 500+ lines" payoff.

## Tasks

### 9a: Delete unused files
- **Delete** `lib/github/push-portfolio.ts` (~200 lines) — all GitHub repo management
- **Delete** `lib/vercel/client.ts` — project creation, domain management, deployment management (the entire file)
- **Delete** `lib/vercel/index.ts` — the barrel export file
- **Delete** `docs/creator-repo-setup.md` — the per-repo GitHub Action workflow guide
- **Delete** `docs/wildcard-dns-vercel-setup.md` — rewrite with new simpler setup (or update in-place)

### 9b: Delete admin API routes for GitHub/Vercel
- **Delete** `app/api/admin/github/connect/route.ts`
- **Delete** `app/api/admin/github/callback/route.ts`
- **Delete** `app/api/admin/github/disconnect/route.ts`
- **Delete** `app/api/admin/github/repos/route.ts`
- **Delete** `app/api/admin/github/status/route.ts`
- **Delete** `app/api/admin/creators/[userId]/link-repo/route.ts`
- **Delete** `app/api/admin/creators/[userId]/repo-status/route.ts`

### 9c: Remove deprecated dependencies
- **Remove** from `package.json`:
  - `@octokit/rest` — no longer needed (unless used elsewhere)
- Run `npm install` / `pnpm install` to clean lockfile

### 9d: DB schema migration (prepare, don't run yet)
- Create a Drizzle migration that drops deprecated columns from `users` table:
  - `vercel_project_id`
  - `github_access_token`
  - `github_refresh_token`
  - `github_username`
  - `github_connected_at`
  - `github_repo_full_name`
  - `github_repo_id`
- **Don't run this migration immediately** — wait until confident nothing references these fields
- Update `lib/db/schema.ts` to remove these columns from the `users` table definition

### 9e: Update admin dashboard UI
- Remove GitHub connection UI (connect/disconnect buttons, repo linking)
- Remove Vercel project ID input
- Remove deployment status/list views
- Simplify the "Enable Site" toggle — it's now just a DB flag, no Vercel API call behind it
- Add portfolio blob management UI if useful (view files, re-upload, delete)

### 9f: Clean up env vars
- Remove from `.env.example` and production:
  - `GITHUB_SERVICE_TOKEN` (if not used elsewhere)
  - `GITHUB_SERVICE_USERNAME`
  - `VERCEL_API_TOKEN` (if only used for portfolio project management)
  - `VERCEL_TEAM_ID` (if only used for portfolio project management)
  - `CREATOR_REGISTRATION_SECRET` (the GitHub Action secret)

### 9g: Delete GitHub repos (optional, last)
- Script to archive or delete per-creator GitHub repos
- Only after confirming blob serving is stable for 1+ weeks
- Optional — repos cost nothing if private, can keep for historical record
