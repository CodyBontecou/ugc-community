## Overview
Pull real data from the creator's profile (bio, social handles, uploaded media, content posts) and inject it into the generation prompt so portfolios contain actual content instead of placeholders.

## Tasks
- Expand `QuestionnaireData` in `portfolio-prompt.ts` to include:
  - `bio: string | null`
  - `socialLinks: { platform: string; handle: string; url: string }[]`
  - `mediaItems: { url: string; type: string; description?: string }[]` (their uploaded work samples)
  - `contentPosts: { title?: string; platform: string; url: string }[]`
- Update data loading in `lib/inngest/functions/generate-portfolio.ts` to query:
  - `users` table for bio, social handles (instagramHandles, tiktokHandles, youtubeHandles, twitterHandles)
  - `media` table for uploaded images/videos with their Vercel Blob URLs
  - `contentPosts` table if it exists for their tracked content
- Update `buildPortfolioPrompt()` to include:
  - A `## Creator Profile` section with real bio and social links
  - A `## Portfolio Content` section listing real media items with URLs
  - Instructions to use these real URLs in `<img>` tags and real social links in the nav/footer
- Update `scripts/generate-portfolio.ts` CLI to also pull the expanded data

## Files
- `lib/agent/portfolio-prompt.ts` (modify — expand types and prompt builder)
- `lib/inngest/functions/generate-portfolio.ts` (modify — load more data)
- `scripts/generate-portfolio.ts` (modify — load more data)

## Acceptance Criteria
- Generated portfolios include the creator's real bio text
- Social media links in the generated site point to real profiles
- If the creator has uploaded media, those real Blob URLs appear in the portfolio section
- Graceful fallback: if no media/bio exists, prompt still works with placeholders
