Read-only UI audit of the live homepage and post-job form on 2026-10-25, including a 390x844 browser viewport. No application code changed.

Prioritized follow-up:
1. Mobile expansion layout: opening the LiftPeak row squeezes compensation into a narrow strip with near-character wrapping, pushing the actual brief far down. Investigate the fixed table's always-five-column detail span while source/posted columns are hidden. Prefer a dedicated mobile card layout or a responsive column model that preserves widths when expanded.
2. Compensation scanability: the first collapsed mobile row measured 312.5px tall. The lengthy compensation paragraph is not visually limited as intended. Show the amount and payment unit prominently, keep complete qualifications in the expanded brief, and verify line clamping in the deployed browser.
3. Button contrast: white text against the coral and rose gradient endpoints computes to roughly 2.05:1 and 2.70:1 respectively. Use a darker primary fill or dark button text and verify the rendered contrast; keep the softer gradient decorative.
4. Mobile action clarity: external applications become an unlabeled visible external-link icon in a 36x36px target. Retain a visible Apply label and provide at least a 44px touch target. Add a clear View brief cue so expansion and external navigation are distinct.
5. Empty popular filter: Posted directly currently returns zero results. Consider counts on shortcuts or replacing that prominent shortcut with an available useful subset, retaining the source dropdown.
6. Employer form: a tall introduction and one long ungrouped form delay the task. Group fields into Job details, Pay and terms, and Applications; clarify required and optional fields and reuse the inset-chevron treatment for compensation type.

This audit establishes usability issues, not a measured conversion lift. Physical-phone testing and engagement measurement remain in job00004.

Implemented all six improvements: responsive list rows replace the fixed table; compensation summaries preserve original rate wording and full terms remain in the brief; shared solid-purple primary actions improve contrast; visible Apply and View brief actions have 44px touch targets; live shortcut counts omit empty categories unless selected; the employer form has three fieldsets, a shorter introduction, explicit optional labels, conditional cash validation, and an inset select chevron.
