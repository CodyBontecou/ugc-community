## Overview
Add an automated quality gate after generation that reviews the output and optionally triggers a regeneration with feedback.

## Tasks
- Create `lib/agent/portfolio-reviewer.ts` with a review function that:
  - Takes the generated HTML/CSS/JS as input
  - Sends them to Claude with a reviewer system prompt
  - Scores on: visual distinctiveness (1-10), code quality (1-10), brand alignment (1-10), mobile responsiveness (1-10), accessibility (1-10)
  - Returns structured feedback with an overall pass/fail and specific critique
- Define a minimum quality threshold (e.g., average score >= 7)
- If the review fails, feed the critique back into a second generation attempt with the original prompt + `## Reviewer Feedback` section
- Limit to 1 retry to cap costs (generate → review → optionally regenerate → done)
- Store review scores in `portfolioGenerations` table (add `qualityScore` column)
- Add the review step to the Inngest function between "generate-with-claude" and "upload-and-activate"

## Reviewer Prompt Should Check For
- Generic/overused fonts (Inter, Roboto, Arial)
- Default-looking color schemes (purple gradient on white)
- Placeholder text that wasn't replaced with real content
- Missing sections (Hero, Portfolio, About, Contact)
- Contact form with correct field names
- Responsive meta viewport tag
- Semantic HTML structure
- Sufficient CSS animations/transitions
- Favicon link tags

## Files
- `lib/agent/portfolio-reviewer.ts` (new)

- DB migration

## Acceptance Criteria
- Every generated portfolio is reviewed before being published
- Low-quality outputs are automatically regenerated with specific feedback
- Quality scores are persisted for monitoring/analytics
- Review adds no more than ~30 seconds to the pipeline
