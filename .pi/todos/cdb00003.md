The index already has a persistent `creator_suppressions` table. Search excludes these usernames even after future uploads. Owner-run D1 operations can apply author-level suppression now.

- Add authenticated admin tools to review source context and suppress/restore individual authors or particular contact values.
- Support contact-level corrections and suppression across future imports; do not simply delete an object checkpoint.
- Define data retention and erasure handling for raw source objects, staged versions, and indexed records. Deleting an R2 upload alone currently does not deindex its historical matches.
- Consider R2 event notifications/Queues when volume requires lower latency; the current five-minute poll scans at most 20 objects per prefix per run and rejects objects over 8 MB (recorded for splitting/retry).
- Add alerting for persistent import errors and abandoned partial staging cleanup if upload volume grows.
