## Overview
Track design choices from past generations and explicitly instruct Claude to avoid recent patterns, ensuring uniqueness across the platform.

## Tasks
- Add columns to `portfolioGenerations` table:
  - `designSeedId: text` (from design seed system)
  - `fontsUsed: text[]` (extracted post-generation)
  - `primaryColors: text[]` (extracted post-generation)
  - `layoutType: text` (extracted post-generation)
- Create `lib/agent/generation-history.ts` with:
  - `getRecentDesignChoices(limit: number)` — queries last N completed generations
  - `buildAvoidanceList()` — returns fonts, colors, layout types to avoid
- After successful generation, parse the CSS to extract:
  - Google Fonts used (from `@import` or `<link>` tags)
  - CSS custom property color values
  - General layout pattern
- Inject an `## Avoid These Recent Choices` section into the prompt:
  - "These fonts were used in recent portfolios, do NOT use them: [list]"
  - "These color schemes were used recently, choose something different: [list]"
- Integrate with design seed selection: exclude recently-used seeds from the random pool

## Files
- `lib/agent/generation-history.ts` (new)
- `lib/agent/css-parser.ts` (new — lightweight extractor for fonts/colors from CSS)
- `lib/agent/portfolio-prompt.ts` (modify — add avoidance section)
- `lib/agent/portfolio-generator.ts` (modify — extract and persist design metadata post-generation)
- `lib/inngest/functions/generate-portfolio.ts` (modify — save metadata after generation)
- `lib/db/schema.ts` (modify — add columns)
- DB migration

## Acceptance Criteria
- Last 10 generations' font/color choices are tracked
- New generations receive an explicit avoidance list
- Design seed selection excludes recently-used seeds
- No two consecutive portfolios share the same primary font or dominant color
