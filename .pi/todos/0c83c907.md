## Overview
Use a headless browser to screenshot generated portfolios and feed the screenshots back to Claude for visual quality review — catching issues that code-only review misses.

## Tasks
- Add Playwright as a dependency (or use a lightweight alternative like Puppeteer)
- Create `lib/agent/visual-reviewer.ts` with:
  - `screenshotPortfolio(html, css, js)` — spins up headless browser, loads the files, takes screenshots at:
    - Desktop (1440px wide)
    - Tablet (768px wide)
    - Mobile (375px wide)
  - Returns screenshots as base64 PNG buffers
- Create `reviewPortfolioVisually(screenshots, creatorContext)` that:
  - Sends screenshots to Claude vision API
  - Asks it to evaluate: layout quality, visual hierarchy, readability, mobile responsiveness, overall aesthetic impression
  - Returns structured scores and feedback
- Integrate into the quality validation step (TODO-b3007a31):
  - After code review, also do visual review
  - Combined score determines pass/fail
- Handle environment constraints:
  - Playwright needs to be available in the worker environment (Fly.io)
  - Consider using a hosted screenshot service as alternative (e.g., screenshotone.com API)
  - Fallback gracefully if screenshots can't be taken
